# KK塔传 1.1.0 发布资料

这是可复制到 Chrome 应用商店开发者后台的文案与填写依据。准备文件不代表扩展已上架或审核通过。

## 名称与简介

名称：KK塔传 · KK宝塔文件上传助手

简介：
在已登录的宝塔文件页面上传文件夹或文件，支持目录自动跟随、打包上传、逐个上传和文件核对。支持多个 Linux 面板版本。

建议类别：开发者工具  
主要语言：简体中文

## 详细介绍

KK塔传让你在宝塔文件管理页面上传整个文件夹或多个文件，免去把大量文件手工拆分选择的操作。

上传前显示服务器地址和完整目录，验证通过后才能开始。空闲时自动跟随当前页面目录；手动目录保持固定，可点击“跟随当前目录”恢复跟随。任务进行中固定使用开始时的目标目录，完成后再同步页面。选择 dist 等文件夹时，默认上传其内容，并保留 assets 等子目录结构；也可以选择保留最外层文件夹。

提供两种文件夹上传方式：
• 打包上传：将纯 ASCII 路径归档后上传解压；中文等非 ASCII 路径直接上传。
• 逐个上传：所有文件依次直接上传，不压缩、不解压。

直接选择 JAR 等文件时，保持文件名并分片上传。整批上传完成后，核对全部选定文件的存在、文件类型和精确字节数，全部通过后播放一次彩纸撒花。核对不等于内容散列校验。也可仅核对服务器文件，或补传中文等特殊名称文件。

无需 SSH 或另配面板 API 密钥，使用当前页面有效的宝塔登录会话。文件直接发送到当前面板服务器，没有第三方中转、广告或统计。

当前支持 Chrome 120 及以上及 Linux 宝塔面板 9.3.0、9.4.0、9.5.0、9.6.0、11.0.0、11.1.0、11.2.0、11.3.0、11.4.0、11.4.1、11.5.0、11.6.0、11.7.0、11.8.0、11.8.1、13.0.0、13.1.0 的直接访问入口。新增版本已核对官方更新包并经本地模拟验证，尚未逐一在真实服务器验证；建议首次在独立目录验证。其他版本、Windows 面板和代理入口暂不支持。文件夹单次最多 60,000 个文件、512 MiB，ZIP 最多 400 MiB。

同名文件会覆盖，其他文件保留；不自动备份、删除旧资源、回滚或重启后端服务。上传期间保持本页打开。

KK塔传是独立第三方工具，与宝塔官方没有隶属关系。

## 权限说明与单一用途

单一用途：
在用户已登录的宝塔文件管理页面，将用户主动选择的本地文件夹或文件上传至用户验证的服务器目录，并核对上传结果。

activeTab 用途：
用户点击扩展图标后，临时访问该标签页，读取面板版本和当前目录，显示上传界面。不会在其他标签页自动运行。

scripting 用途：
向用户点击的标签页注入扩展包内的本地脚本，提供文件选择、目录验证、上传和结果核对。

远程代码：
不使用。脚本、归档实现和彩纸库随包提供；不下载执行远程脚本。

数据用途：
用户选择的文件内容和路径直接发送到其当前宝塔服务器，用于文件上传。当前页面登录校验令牌只用于同源认证。开发者和第三方不接收这些信息。后台关于数据类别的声明应结合当前表单措辞如实填写，不能把“开发者不收集”误写成“扩展完全不处理文件或认证信息”。

## 提交前需由发布者补齐

1. 开发者账号、发布者显示名称、联系/支持邮箱及可选支持页面，不在本地文件中编造。
2. 将本目录的 privacy.html 部署到发布者控制的稳定公开 HTTPS 地址，在后台填写真实隐私政策链接。policy 与随包 PRIVACY.md 内容一致。
3. promo-440x280.png 为宣传图；preview.jpg 为 1.1.0 在本地 v13.1.0 模拟页面的预览。该图为 1280×720，提交商店前需补充符合要求的 1280×800 或 640×400 当前版本截图。演示图片应标明用途，不能冒充用户实际服务器或宝塔官方背书。128 像素应用图标在 icons/，包含透明留白。
4. 上传 releases 中的 kk-tachuan-1.1.0.zip。ZIP 根目录直接包含 manifest.json。
5. 核实文案、权限和数据声明后，由发布者提交审核；本项目没有代为提交或公开发布。

应用图标位于 icons/，原始矢量稿在 publishing/icon.svg；不使用宝塔官方图标。旧版发布包和内部记录不进入 1.1.0 扩展包。
