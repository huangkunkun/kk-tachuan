# KK塔传 1.1.0 兼容性说明

## 支持范围

当前开放 Linux 宝塔面板 **v9.3.0、v9.4.0、v9.5.0、v9.6.0、v11.0.0、v11.1.0、v11.2.0、v11.3.0、v11.4.0、v11.4.1、v11.5.0、v11.6.0、v11.7.0、v11.8.0、v11.8.1、v13.0.0、v13.1.0** 的直接访问入口，要求 Chrome 120 及以上，已登录且在文件管理页面。仅列出的精确版本开放；代理管理入口、Windows 面板和其他管理面板尚未适配。版本号符合也不能保证定制面板、权限策略或其他插件环境完全兼容。

既有打包上传流程已得到使用者在 v11.7.0 实际服务器上传成功的反馈。v11.3.0 已核对官方历史更新包，并通过本地自动化与浏览器演示环境验证。1.1.0 新增的版本已静态核对官方更新包，并在本地模拟接口中验证；尚未在这些版本的真实服务器逐一验证完整流程，也未在使用者正式服务器写入文件或执行部署。首次用于实际服务器时，请先在独立空目录验证路径、上传与核对结果。

## 目录与文件处理

上传目标必须是完整 Linux 路径。插件从当前文件管理页面读取目录；读取不到时需手工填写。目录验证比较面板返回的完整路径，不接受面板静默回退的其他路径。

每次写入前还会只读查询目标目录的文件元数据，核对返回路径、类型及大小字段。接口不兼容时停止写入。此检查不验证上传权限、上传行为或解压是否成功；上传后仍会逐文件核对。

空闲时自动跟随当前页面目录，目录变化后重新验证；读取不到目录或验证失败时禁用上传。手工修改目标后暂停跟随，点击“跟随当前目录”恢复。上传与核对任务开始后固定目标，任务结束后再同步页面目录；结果区保留该次任务的实际目标。快速切换时取消旧目录验证并忽略迟到响应，避免旧结果覆盖新目录。

打包方式将纯 ASCII 相对路径写入 ZIP，中文等非 ASCII 文件名或上级目录名使用面板原生分片上传协议。逐个方式将所有文件按顺序上传，两种方式都保留子目录结构。所选根文件夹默认去除，可勾选保留。

打包 ZIP 在服务器解压，插件不通过 SSH 连接，也不打开远程终端。插件调用当前登录会话可访问的面板文件接口，由面板服务执行上传、建目录和解压。

核对覆盖全部选定文件的完整路径、普通文件标识及精确字节数。核对是元数据比对，不是内容散列比对；存在且同大小不能证明内容相同。核对不完整、文件缺失或大小不同均不显示完成。诊断最多显示前 20 个问题文件，汇总仍覆盖完整清单。

## 限制

- 单次最多 60,000 个文件，文件夹原始总大小最多 512 MiB；ZIP 最多 400 MiB。
- 根据浏览器能力生成压缩或未压缩 ZIP；单文件使用 2 MiB 分片。
- 部分面板不接受的路径特殊字符会提前拒绝。浏览器选择不会保留空目录、Linux 权限或符号链接语义。
- 写入同名文件即覆盖；无自动备份、旧资源删除、回滚、服务重启和跨窗口锁。
- 同一服务器建议顺序操作；不同页面写入同一目标可能相互覆盖，面板解压可能共用日志。
- 请求中断、登录失效、服务器权限或保护拦截会停止流程。取消不会撤销已完成的写入。
- 成功时只清理本次随机 UUID 暂存目录；失败遗留目录和历史乱码文件需自行检查处理。
- 任务依赖当前页面，上传期间不要关闭、刷新或导航离开。

## 技术依据

接口适配参考宝塔官方仓库 [aaPanel/BaoTa](https://github.com/aaPanel/BaoTa) 提交 `f9f6845c4d3bd71a16bce0118f8549909e7a802e` 中的文件管理页面与 `class/files.py`。该参考不等同于每台服务器实际安装内容的快照。

v11.3.0 的依据是 [宝塔官方下载的历史更新包](https://download.bt.cn/install/update/LinuxPanel-11.3.0.zip)，SHA-256 为 `16d043ed0eb446079eb7a8cc6426fb86b486ccfbcf82a6318fae72c57e818c55`。核对了页面模板、前端目录状态和上传器、文件接口以及会话校验入口；该包页面使用 `#root` 挂载，目录状态仍为 Pinia 的 `FILES-STORE.fileTabActiveData.param.path`。

两个参考实现中的 `GetDirNew`、`CreateDir`、`upload`、`upload_files_exists`、`UnZip`、`DeleteDir` 六个接口，在移除源码位置、注释和文档字符串后，函数可执行语法树一致。当前协议可共用，页面挂载位置的差异已分别处理。

新增版本的逐包对照结果保存在项目源码的 `docs/reference/version-audit.json`；发布包不包含宝塔源码。11.4.0、11.4.1、11.5.0、11.6.0、11.8.0、11.8.1、13.0.0、13.1.0 的六个方法与 11.3.0 参考一致；9.3.0、9.4.0、9.5.0、9.6.0、11.0.0、11.1.0、11.2.0 的五个方法一致，`GetDirNew` 的差异集中于文件所有者名称处理。已检查页面令牌、版本信息、挂载点及文件状态相关标识；这些静态检查不等于真实服务器运行验证，也不涵盖所有被调用的辅助函数。

请求仅发送至当前面板来源的 `/files?action=...`，复用浏览器同源会话和页面登录校验令牌，不绕过登录校验。使用的文件接口为 `GetDirNew`、`CreateDir`、`upload`、`upload_files_exists`、`UnZip` 和 `DeleteDir`。不调用通用命令执行接口。

所有脚本随扩展提供。上传界面和任务在当前页面运行，组件版本不一致时停止。彩纸采用独立画布，播放完成自动清理，遵循减少动态效果偏好；动效失败不改变上传结果。

目录跟随每 400 毫秒读取页面现有目录状态，未变化时不发送服务器请求；只在路径变化或主动验证时调用目录接口。后台页面暂停跟随，回到页面时立即同步；关闭或替换界面时清理定时器、事件监听和未完成的目录验证。
